# MATRIX BLUETOOTH ENGINE — مشروع PS3 Homebrew

## الحالة الحالية
هذه حزمة بداية للمشروع: هوية التطبيق، الأيقونة، هيكل المصدر، وملف إعداد أولي للبناء باستخدام PSL1GHT.

**ليست هذه نسخة PKG جاهزة للتثبيت، وليست وظائف Bluetooth منفذة بعد.** لا يصح الادعاء بأن البحث أو الاقتران أو نقل الملفات يعمل قبل ربط واجهات النظام واختبارها على جهاز PS3 حقيقي.

## الهدف
- اسم XMB: MATRIX BLUETOOTH ENGINE
- APPID المقترح: MTXBT001
- النظام المستهدف: PS3 CFW 4.93.2 CEX (يحتاج اختبار توافق)
- SDK: PSL1GHT / ps3dev

## خطة التنفيذ
1. بناء تطبيق Homebrew تجريبي وتشغيله على الجهاز.
2. فحص واجهات Bluetooth المتاحة في GameOS/CFW دون افتراض وجود API عامة.
3. تنفيذ اكتشاف الأجهزة والاقتران وفصل الاتصال حيث تسمح الواجهات.
4. دراسة دعم الصوت ونقل الملفات بشكل مستقل؛ قد لا يتيحهما تطبيق Homebrew عادي.
5. اختبار كل وظيفة فعلياً ثم إصدار PKG.

## البناء
يتطلب بيئة PS3DEV وPSL1GHT كاملة ومهيأة، وليس Android SDK أو Java العادي.
بعد توفير بيئة البناء، راجع إعدادات Makefile وجرّب:

```sh
make
make pkg
```

قد تحتاج إلى تعديل مسارات الأدوات حسب تثبيت PSL1GHT لديك.

## ملفات المشروع
- `assets/MATRIX_BLUETOOTH_ENGINE_ICON.png` — الأيقونة/التصميم الأولي.
- `src/main.c` — نقطة دخول أولية فقط، لا تنفذ Bluetooth ولا واجهة رسومية بعد.
- `Makefile` — قالب أولي يحتاج بيئة PSL1GHT.
